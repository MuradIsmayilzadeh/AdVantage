# AdVantage

Marketing site for a social media marketing studio, built with Next.js 14 (App Router) and MongoDB.

## Features
- Package listing and package detail pages
- Custom plan request form, About and Contact pages
- `/api/packages` endpoint backed by MongoDB, with built-in sample data when no database is configured

## Getting started
```bash
npm install
cp .env.example .env   # optional: add your MongoDB connection string
npm run dev
```
Open http://localhost:3000.
